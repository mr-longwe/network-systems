# Network Systems Development

A practical implementation project exploring the design, deployment, integration and management of network-connected systems.

## Overview

This project focuses on developing a networked video monitoring system using locally available hardware and software resources.

It explores the networking infrastructure and software components required to connect multiple devices, transport video over IP networks, perform local processing and establish secure remote connectivity.

Development begins within a residential LAN/WLAN environment and progressively investigates more advanced networking concepts, including VPN connectivity, network monitoring, automation and cloud networking.

## Technical Domains

- **Network Infrastructure:** Ethernet, Wi-Fi, LAN/WLAN architecture, IPv4, DHCP, routing and network troubleshooting.
- **IP Communication:** RTSP, TCP/IP, networked video sources and multi-device communication.
- **Edge Computing:** Local video reception, processing and storage using Python and OpenCV.
- **Secure Connectivity:** VPN deployment, WireGuard, routing and firewall configuration.
- **Network Automation:** Python-based diagnostics, monitoring and operational automation.
- **Cloud Networking:** Cloud connectivity, distributed infrastructure and infrastructure automation.

## Development Objectives

- Design and validate a functional LAN/WLAN environment.
- Integrate multiple network-connected video sources.
- Implement reliable local video reception and processing.
- Investigate network performance, availability and failure conditions.
- Establish secure remote access through VPN connectivity.
- Develop network monitoring and automation capabilities.
- Explore cloud-integrated network architectures.

## Development Approach

Development follows an experimental and evidence-based approach.

Each stage is supported by technical documentation, network diagrams, configuration records, validation tests and performance observations.

Implementation results are documented separately from proposed improvements and future development objectives.

## Initial Environment

The initial implementation uses:

- A residential 4G/5G Fixed Wireless Access connection.
- An Ethernet-connected Windows workstation.
- Android devices operating as wireless IP video sources.
- Python and OpenCV for local video processing.
- Existing LAN/WLAN infrastructure for device communication.

## Long-Term Direction

The project provides a practical foundation for developing expertise in network infrastructure, networked systems, secure connectivity, network automation and cloud networking.

It will evolve through incremental implementation, testing and technical documentation.
